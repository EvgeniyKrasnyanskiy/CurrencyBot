# План реализации: Антиспам-модерация темы «Обмен» с отложенным удалением

## Цель
Автоматизировать модерацию темы (топика) «Обмен» в Telegram-супергруппе:
- Сохранять корректные объявления о покупке/продаже криптовалюты.
- Нарушающие сообщения (спам, медиа, нерелевантный чат) помечать предупреждением в reply.
- Разрешать текстовые ответы участников на существующие объявления об обмене.
- Через настраиваемый интервал (по умолчанию 60 сек) автоматически удалять как нарушающее сообщение, так и ответ бота с предупреждением.
- Приветственное объявление с правилами публиковать однократно при старте.
- Сохранить функционал публикации курсов и волатильности в неизменном виде.

---

## Архитектура и компоненты

### 1. `moderation/config.py`
Параметры конфигурации из `.env`:
- `MODERATION_ENABLED`: включение/выключение модерации (`True`/`False`).
- `MODERATION_TARGET_GROUP_ID`: ID целевой группы (или `CHANNEL_ID`).
- `MODERATION_TARGET_THREAD_ID`: ID топика «Обмен» (`message_thread_id` или `TOPIC_ID`).
- `WARNING_DELETE_DELAY`: задержка перед удалением в секундах (по умолчанию `60`).
- `WELCOME_MESSAGE_ENABLED`: публикация правил при старте (`True`/`False`).
- `ALLOW_REPLIES_TO_ADS`: разрешение ответов пользователей на объявления (`True`).
- `MAX_ACTIVE_ADS_PER_USER`: лимит активных объявлений (по умолчанию `1`).
- `MODERATION_WHITELIST_USERS`: список ID пользователей/админов, исключенных из модерации.

### 2. `moderation/classifier.py`
Классификация сообщений:
- `EXCHANGE`: корректное объявление об обмене криптовалюты.
- `EXCHANGE_REPLY`: текстовый ответ пользователя на чужое объявление в ветке (не удаляется).
- `SPAM`: запрещенные медиа (стикеры, GIF, голосовые, видео, видеосообщения/кружочки, аудио, фото) либо явный спам/ссылки.
- `CHAT`: обычное общение, флуд, вопросы не по теме обмена.
- `UNKNOWN`: неоднозначные сообщения. Не удаляются автоматически, фиксируются в лог для донастройки правил.

### 3. `moderation/storage.py`
- Хранение состояния в `data/moderation_state.json`:
  - `welcome_sent`: отправлены ли правила в топик (предотвращает повторную отправку при рестарте).
  - Активные объявления пользователей (для проверки лимита `MAX_ACTIVE_ADS_PER_USER`).
- Корректная обработка редактирования сообщений (не считается новым объявлением).

### 4. `moderation/handler.py`
- Фильтр сообщений: только целевая группа и топик.
- Игнорирование сообщений бота и администраторов.
- Логика удаления с задержкой:
  1. Бот отправляет reply на сообщение нарушителя с указанием причины.
  2. Запускается фоновый таймер (`threading.Timer`) на `WARNING_DELETE_DELAY` секунд.
  3. По истечении таймера бот удаляет исходное сообщение и сообщение с предупреждением.
- Логирование действий в `logs/moderation.log`.

### 5. `currency_bot.py`
- Точечное подключение хэндлеров модерации в `CurrencyBot._setup_handlers()`.
- Вызов однократной отправки правил (если включено).
- Публикация курса (`periodic_update`) остается нетронутой.
